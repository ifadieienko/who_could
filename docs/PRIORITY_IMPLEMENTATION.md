# Покрытие приоритетов мастерской

| Приоритет | Требование | Реализация |
|---|---|---|
| P0 | Мастерские, сотрудники, изоляция | Workshop/Membership, tenant scope на API и файлах, роли all/own |
| P0 | Отключение без потери заказов | active=false; история и назначения сохраняются; владелец защищён от потери доступа |
| P0 | Согласованные ремонт и выдача | Один RepairOrder, разрешённые переходы, QC, проверка актуальной сметы и расчёта, снимок выдачи |
| P1 | Общий процесс и журнал | Версионный граф, назначение/переназначение, аудит, optimistic locking |
| P1 | Кастомные поля и версии | Типы, секции, сетка/строки, условия, обязательность и права; назначение формы и закреплённый снимок |
| P1 | Формы диагностики, ремонта, проверки | Три отдельных шаблона и вкладки; обязательность на выходе этапа и при выдаче; версии не меняют прежние заказы |
| P1 | Файлы, миниатюры, пагинация | Постоянный volume, нормализация фото, защищённые оригиналы/миниатюры, страницы заказов и курсоры фото/журнала |
| P1 | Карточка, QR, этикетка | Постоянная ссылка на заказ, мобильный интерфейс, QR и печать этикетки 62×40 мм; авторизация сотрудника |
| P2 | Сметы, согласование, документы, уведомления | Версии смет, срок и хеш согласования, акты приёма/выдачи, платежи ремонта, SMTP outbox/retry |
| P2 | Подписки, тарифы, оплата | Stripe Checkout/Portal/webhook, Starter/Pro/Business, квоты сотрудников/заказов/фото, экран потребления |

Настройка и границы версии описаны в [WORKSHOP_RELEASE.md](WORKSHOP_RELEASE.md). Онлайн-платежи и отправка писем требуют действующих настроек провайдеров; реальные операции здесь не выполнялись. Счета/фискализация, SMS и произвольные формулы конструктора в эту реализацию не входят.

Проверено локально: 31 серверный тест и миграция заполненной старой схемы на SQLite; 3 браузерных сценария Chromium; сборка frontend. Два конкурентных теста требуют MariaDB и локально пропущены. Все 33 серверные проверки, миграции и браузерные сценарии запускаются в GitHub Actions; результаты публикации доступны в [PR №1](https://github.com/ifadieienko/who_could/pull/1).
