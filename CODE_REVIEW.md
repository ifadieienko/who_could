# Проверка версии мастерской

## Исправленные проблемы прежней архитектуры

| Проблема | Изменение |
|---|---|
| Нет границы между мастерскими; глобальное администрирование | Workshop + Membership + разрешения; API и файлы ограничены мастерской, старые глобальные маршруты отключены |
| Удаление сотрудника может удалить рабочую историю | Отключение membership; новые ссылки на сотрудников с RESTRICT; история сохраняется |
| Личные доски и выдача хранят несогласованные состояния | Единая запись RepairOrder, явные допустимые переходы, проверки и единая выдача |
| Изменения формы/процесса меняют смысл старых заказов | Версии шаблонов/процессов, неизменяемые снимки внутри заказа |
| Параллельная запись затирает работу другого сотрудника | Version + блокировка строки; устаревшее изменение получает HTTP 409 |
| Изображения раздувают карточки и базу | Защищённые файлы и миниатюры; лимит, проверка декодирования, удаление EXIF; преобразование старых фото |
| QR может раскрывать заказ постороннему | QR содержит адрес сотруднической карточки; доступ требует сессии и прав |
| Приёмка и выдача не фиксируют факты передачи | Снимок приёмки, фото, получатель, проверки, акт; прежняя выдача остаётся в аудите после повторного открытия |
| Нет подтверждения стоимости конкретной версии | Неизменяемые сметы и отдельная одноразовая операция решения по токену; устаревшая ссылка не действует |
| При отклонённой новой смете могла исчезнуть стоимость при выдаче | Выдача с существующей сметой требует её актуального согласования; задолженность требует отдельной причины и финансового разрешения |
| Нет отзыва сессии и восстановления доступа | Серверные LoginSession, отзыв при logout/reset, одноразовый reset token, same-origin для записи |
| Нет переноса данных и независимой копии мастерской | Проверяемый CSV, идемпотентные внешние ID, полный ZIP; read/export после окончания подписки |
| Установщик и документация обещали неподдерживаемую SQLite production | MariaDB для приложения, SQLite только для изолированных тестов; установщик явно требует настройки БД |
| SQL backup не сохранял новые файлы | Сопутствующий архив uploads, off-host копирование обоих компонентов, восстановление файлов |

Серверные зависимости обновлены до FastAPI 0.141.1 / Starlette 1.6.0; это включает исправления [известной DoS-ошибки FileResponse](https://github.com/Kludex/starlette/security/advisories/GHSA-7f5h-v6xp-fcq8) и [ограничений парсинга форм](https://github.com/Kludex/starlette/security/advisories/GHSA-82w8-qh3p-5jfq). Обновлены python-dotenv и уязвимые транзитивные npm-зависимости. Аудит отражает известные на момент проверки записи, а не отсутствие всех возможных уязвимостей.

## Проверки в коде

`backend/tests` покрывает изоляцию, роли, деактивацию, конфликты версий, формы/условия/скрытые поля, переходы, сметы, фото, документы, импорт, экспорт, выдачу, гарантию, повторное открытие, сессии/reset, SMTP retry и подпись/replay webhook. Отдельная заполненная база версии 0008 проверяет реальный перенос и повторяемое преобразование фото, включая повреждённое изображение.

Playwright проходит пользовательский цикл от регистрации до выдачи, включая согласование в отдельном браузерном контексте, фото и мобильное открытие QR-карточки. GitHub Actions дополнительно запускает API на MariaDB 11.4 и проверки deployment-скриптов. Наличие workflow не означает успешность конкретного запуска: результат смотрите в Checks соответствующего commit/PR.

Ограничения продукта, последовательность выпуска и внешние интеграции перечислены в [WORKSHOP_RELEASE.md](docs/WORKSHOP_RELEASE.md). Настоящие платежи, SMTP-доставка и восстановление production-сервера требуют отдельной эксплуатационной приёмки. Ревью и тесты не являются гарантией отсутствия всех возможных дефектов.
